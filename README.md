# ⚡ Afriquia Energies

### Smart Electric Vehicle Charging Platform

**Afriquia Energies** is my main academic/project concept around the future of electric mobility.

The goal is to transform the traditional charging-station experience into a **smart, connected and predictive platform**.

The platform is designed to help drivers:

📍 Find nearby charging stations
⏱️ Estimate waiting time
🔋 Estimate charging duration
📅 Reserve charging slots
📊 Follow station availability
🤖 Use AI-assisted predictions
🔄 Interact with real-time queues

### Technical Concept

Google Maps
